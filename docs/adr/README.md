# ADRs (Architecture Decision Records)

Use este diretório para decisões arquiteturais relevantes.

## Quando abrir ADR

- Mudança de padrão arquitetural.
- Inclusão de nova tecnologia core.
- Alteração de limites entre camadas/módulos.
- Mudança de política de dados, auditoria, segurança ou rollout.

## Fluxo

1. Criar ADR via template.
2. Discutir no PR.
3. Aprovar com CODEOWNERS.
4. Marcar status final (Aceita, Rejeitada, Substituída).
