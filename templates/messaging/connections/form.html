O que é uma Conexão?

Uma conexão representa uma instância do WhatsApp conectada à API. Cada conexão corresponde a um número de telefone do WhatsApp.

ID da Instância

O ID da instância é um identificador único usado para comunicar com a API. Use apenas letras, números e hífens.

Webhook

Configure um webhook para receber notificações quando novas mensagens chegarem. Isso permite que seu sistema responda automaticamente.
